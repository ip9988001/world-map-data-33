## 一、断链怎么实现的（唯一真值 = `collect/chain_policy.py`）

| 约束 | 内容 |
|---|---|
| ① 接续表 | `04b→05b`、`05b→07b`、**`07b→（空）`**、`10b→（空）` |
| ② 允许清单 | `ALLOWED=("05b","07b")`；NEXT 不在此列（如手滑写回 `10b`）→ `stop / next_not_in_allowlist` |
| ③ 子 run chain | `CHILD_CHAIN={04b:0,05b:0,07b:0,10b:0}` → 单跳不级联；**硬编码 `-f chain=1` 已删** |
| ④ 重阶段闸门 | `plan` job 第一步：`stage=10b` 且 `authorize_heavy!=1` → `::error::` 直接失败 |
| ⑤ 默认值 | `chain` 输入默认 `1` → **`0`** |

workflow 侧只做「读结论 + 执行」：`python3 collect/chain_policy.py --stage $STAGE --chain ${{ inputs.chain }} --write-env /tmp/chain.env`
→ `source /tmp/chain.env` → 按 `CHAIN_DECIDE / CHAIN_NEXT / CHAIN_CHILD_CHAIN` 决定是否 `gh workflow run`。
条目级三道闸门（片齐 / `failed=0` / `complete=true`）原样保留在前。
