## 2. 整个 main 回到备份 tag（真回退，会动远端 main）

> 代价：`backup/pre-freeze-20261031` 之后的提交会从 main 消失（但仍在 reflog / tag 里，可再回来）。
> **回退前先确认没有 in_progress 的 collect run 会往 main 写账本**（否则 CI 立刻把 main 推回新状态）。
> 查在跑的 run：`gh run list --repo ip9988001/world-map-data-33 --workflow collect-full.yml --limit 5 --json databaseId,status,conclusion`

```bash
# 2.1 查清「要丢掉什么」（这一步只读，务必先看）
cd /data/workspace/world-map-data-33 && git fetch -q origin --tags && git log --oneline backup/pre-freeze-20261031..origin/main
# 2.2 建回退分支（不直接动 main，先在自己分支上验；要「回到动手之前」就把 tag 换成 -early）
git checkout -b revert/to-backup-20261031 backup/pre-freeze-20261031
# 2.3 方案 A（推荐，保留历史）：把 tag 之后的全部提交一键反向提交（不直接改写历史）
git checkout main && git reset --hard origin/main && git revert --no-commit backup/pre-freeze-20261031..origin/main || true
git status --short | head -5   # 审一遍再 commit
# 2.4 方案 B（硬回退，历史被改写，需强推）：从 tag 重建 main
git checkout -B main backup/pre-freeze-20261031 && git push --force-with-lease origin main
# 2.5 回退后自检：main 与 tag 必须同 sha
git rev-parse HEAD origin/main backup/pre-freeze-20261031^{}
```

## 5. 账本文件回退（**这些是数据，不是代码 —— 回退=丢记录，先看清丢哪几层**）

`collect/<stage>_ledger.json` = 阶段级汇总；`collect/ledger/<stage>_shardNN.json` = 片级账本（CI 每片跑完自己 commit 到 main）。

| 文件 | 现状（冻结时） | 回退后会丢 |
|---|---|---|
| `collect/04b_ledger.json` | 272 层（ok 253 / partial 5 / missing 7 / unverified 6 / empty 1），`complete=false` | 冻结点之后对 04b 阶段级账本的重建/改判（层结论、gap 说明） |
| `collect/ledger/04b_shard00.json` | 1 片（定向 run 片 0，ok 5 / failed 1） | 该片新的逐层结论 |
| `collect/ledger/05b_shard{00,01,02,04,05,07}.json` | 各 200 层（合计 1,200 层 / **19,406,665 行**，截至 22:22 UTC 快照；run 还在跑会继续涨） | **这 6 片 1,200 层的采集记录**（ok 1,183 / failed 8），行数统计、每层 tag / 单元数 |
| `collect/05b_ledger.json` | 0 层（`shards_incomplete=[0..13]`，in-progress run 还没收敛） | 上一轮 05b 的「未完成片」留痕 |

```bash

cd /data/workspace/world-map-data-33 && git diff --name-status backup/pre-freeze-20261031..origin/main -- collect/ledger collect/*_ledger.json
git diff backup/pre-freeze-20261031..origin/main -- collect/ledger/05b_shard00.json | head -40
# 5.2 回退单个片账本（例：片 02 判错了）
git checkout backup/pre-freeze-20261031 -- collect/ledger/05b_shard02.json && git commit -m "revert(ledger): 05b 片 02 账本退回冻结版"
# 5.3 回退整个阶段级账本
git checkout backup/pre-freeze-20261031 -- collect/04b_ledger.json && git commit -m "revert(ledger): 04b 阶段级账本退回冻结版"
# 5.4 回退后必须重算一遍，确认口径没崩（--check 应 IDENTICAL）
python3 collect/ledger_rebuild.py --stage 04b --plan collect/ledger/04b_plan.json --run-id 41019004076,41092912755,41114330819,41116421397 --out /tmp/rebuilt.json --check
```

> ⚠️ **顺序很重要**：`run 41123309047`（05b）还在跑，每片跑完会把 `05b_shardNN.json` + `05b_ledger.json` 重新 commit 到 main。
> 在它停之前回退这些文件 = 几十分钟后又被覆盖。要回退账本，**先等 run 结束**（或明确接受「回退无效」）。

## 6. 临时分支 / 未收尾改动怎么丢弃

```bash

cd /data/workspace/world-map-data-33 && git stash push -u -m "freeze-20261031 未收尾" && git stash list | head -3
# 6.2 丢掉某个临时分支（例：chore/4-7-freeze 不要了）
git branch -D chore/4-7-freeze && git push origin --delete chore/4-7-freeze   # 只删工作分支，备份 tag 不动
# 6.3 找回被误删的分支（本地 reflog 兜底，30 天内有效）
git reflog | grep -m1 "chore/4-7-freeze" && git branch chore/4-7-freeze <上面查到的 sha>
```
