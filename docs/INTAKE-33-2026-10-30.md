# 三仓 intake v1 落地 + 5 层验收（2026-10-30）

契约：二仓 `schema/SCHEMA.json` **v2.0 rev2（LOCKED）** 的 19 个主字段 + 4 个三仓溯源列；本文件不定义任何新规范字段。

## 一、分流规则（三表 + 拒绝）

| 表 | 收什么 | 主键 |
|---|---|---|
| `addr` | 点层且五道门禁全过 | `addr_id` = sha1(state\|county_fips\|归一化地址键) |
| `aux_parcel` | **全部宗地行**（situs） | `aux_key` = `p:` + sha1 |
| `aux_street` | **全部线层行**（street_line） | `aux_key` = `s:` + sha1 |
| `aux_addr_nohouse` | 点层里「有街名、无门牌号」 | `aux_key` = `n:` + sha1 |
| `REJECT` | 门禁不过且无处安放的行 | 带 `reject_reason` |

**宗地绝不出地址行**：`route()` 里 `parcel_situs` 在门禁判定**之前**就返回 `aux_parcel`，任何宗地行都不可能进 `addr`。依据是实测：55 个宗地层里 12 层 situs 与 mailing 字段并存，冲突率 100%（`analysis/parcel_conflict.json`），mailing 是业主外地/PO 信箱，当 situs 用会把地址系统性写错。测试 `collect/tests/test_intake_33.py::test_parcel_never_addr` 锁这条。

五道硬门禁（任一不过 → 不进 `addr`）：`no_house_number` / `no_street_name` / `state_invalid` / `geo_missing` / `county_unresolved`（县一律射线法多边形判定，**禁用 bbox**）。
