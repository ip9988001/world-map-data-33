## 二、可加性（已核，不是假设）

1. **层 id 交集为 0**：04b∩05b = 0，04b∩07b = 0，05b∩07b = 0。
2. **上游 url 交集为 0**：三对阶段的所有层 url 两两比对，交集均为 0（每层都能在 `layer_plan.csv` 查到 url）。
3. **base 名撞车 4 组，但不是同一上游层**：同一服务名被不同 host 托管，url 不同、declared 不同。例如
   `_rest_services_Site_Structure_Address_Points_FeatureServer_0`：04b 是 `services.arcgis.com/jjSk6...`（559,467 行），
   05b 是 `services.arcgis.com/xSPs49...` / `services7.arcgis.com/6Ys1qj...` 等（27,079 / 9,727 / 87,302 行）。
   详细逐层 url 见 `analysis/4-7-total-2026-10-31.json` 的 `additivity.base_name_collisions_different_hosts`。
4. **04b capped 层与 05b/07b 无重叠**：`s_Points_from_National_Address_Database_view_FeatureServer_0`
   （39,875,268 行）按层 id 与 url 都不在 05b/07b。它的 39.8M 行只影响「原始 rows」，不影响「可核实实采」和缺口。
