# 搭建 SOP —— 七步 D0~D6

> 每步都有**放行闸门**，闸门不过不许进下一步。
> 跳步 = 该轮作废。这是母体里唯一不允许「灵活」的部分。

---

## D0 立项判定（不过就不许进自研模式）

**三问，有一个否 → 不进**：

1. 结果**可复算**吗？（行数、hash、测试、schema、覆盖率能机器算）
2. 失败**可观测**吗？（能不能看出「没成」）
3. 能**分片**塞进单 job 时限吗？（超时限作业必须可切片）

**产物**：`MISSION.md`
- 目标（一句话，可判真假）
- 不可接受的结果（红线，例：数据丢行、静默截断、口径混用）
- 预算（时间上限 / 费用上限 / 存储上限）
- 可跳过的边界（只有 `upstream` 类可跳，且必须留痕）

**闸门**：MISSION.md 里「目标」能被第三方判真假；「红线」写的是结果不是过程。

> 主观验收（「像不像」「满不满意」）必须事先转成代理指标（字段覆盖率、DOM diff、SSIM），否则无人闭环一定走向自己宣布成功。

---

## D1 契约先行（先写判据，再写代码）

每个环节一份 `STEP-0X.md`，五段必填：

1. 目标
2. 输入（从哪来、什么格式、可能缺什么）
3. 产出（文件路径、命名、大小量级）
4. **验收判据**（机器可算的表达式，不是形容词）
5. 常见失败形态对照表（症状 → 分类 → 动作）

**闸门**：随便挑一份 STEP，判据能被写成一行可执行断言。写不成 → 回去重写，不许进 D2。

> 顺序倒了必然变成「代码写完再编标准」，这是所有假验收的源头。

---

## D2 骨架落地

1. 复制 L1 骨架（见 `04-骨架与适配器.md`）
2. 填 MISSION + STEP
3. 生成步骤配置（单一入口，改一处同步全部工人）
4. 建 append-only 账本（见 `02-契约.md` 第二节）
5. 建 blocked 档案（带状态机）
6. 接入信箱（信封规范见 `02-契约.md` 第一节）
7. 跑 selftest 四断言

**闸门**：selftest 全绿；lint 零告警。

---

## D3 单层干跑（最贵的一步，绝不能省）

只跑 **1 层**，走完整链路，并**故意注入三类失败各一次**：

- 注入一个坏 URL → 必须被分成 `upstream` 并记档
- 注入一个必 400 的参数 → 必须被分成 `logic` 并阻断（**不许重试**）
- 注入一次 5xx → 必须被分成 `transient` 并自动重跑成功

**放行闸门（四条全中才准放量）**：
1. 1 层成功，产物可下载
2. `upstream` 正确记档且带状态机
3. `logic` 正确阻断，重试次数 = 0
4. 账本行数与 declared 精确吻合（差额为 0，或差额已逐条解释）

---

## D4 小样本放量（30~150 层）

目的**不是拿数据，是测速率**。

- 实测「秒/层」→ 外推全量 ETA → 写入 `expected_done_at`（再加 1.5 倍冗余）
- 观察失败分布是否与 D3 的对照表一致

**闸门**：`expected_done_at` 来自实测而非估算；失败分布无「未知分类」项。

> 「超期报警」可信的前提：速率是这个仓库实测出来的。

---

## D5 全量

- **分片单位** = 单 job 时限 × 实测速率 × 60%（反算得出，不是拍 200 层）
- 每片自带断点续跑 + 独立账本
- 幂等：dedupe key = 环节 + 层 + 事件，重投不重处理
- 心跳：每 N 分钟一条廉价进展；**超期判定发生在信箱侧，不在工头**

**闸门**：任取一个分片重跑，账本不重复、不丢行。

---

## D6 收尾归档

1. 产物按规则打包压缩，发 Release（不许只留在 runner 或本机）
2. 账实对齐三件套：workflow 全绿 + 产物可下载 + 差额逐条解释
3. 复盘写进 `06-复盘/`，**只允许写回两处**：L2 适配器、各 STEP 的失败形态对照表
4. 空仓再造验收（见 `03-可靠性与验收.md`）——可选，但母体每次大改后必须做

**闸门**：三件套齐；Release 说明含完成度 / declared vs 实际 / 有效数 / 失败数 / 残缺层清单。

---

## 附：七步常见死法

| 步 | 常见死法 | 后果 |
|---|---|---|
| D0 | 目标写成「尽量抓全」 | 无法判真假，永远没有完成态 |
| D1 | 判据写成形容词 | 验收变成感觉，假绿 |
| D2 | 账本覆盖写 | 历史被冲掉，增量重跑无从谈起 |
| D3 | 跳过失败注入 | 三分法没被验证，放量必炸 |
| D4 | ETA 靠拍 | 超期报警全是假红，最后被无视 |
| D5 | 分片按层数拍 | 顶到 6h 上限被砍，半截产物 |
| D6 | 只 commit 不发 Release | 产物单副本、随 runner 消失 |
