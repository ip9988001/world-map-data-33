# STEP 05 — 县市碎片放量

**目标**：把剩下的两万层全部扫完，不留下 pending。

**方法**
- 分批：每批 200~500 层，一批一个 workflow run
- 全自动滚动：一批完 → herald 判验收 → 自动触发下一批
- 失败层进 `failed_layers.json`，最后统一重跑一轮

**产出**：全部层状态落账 + 按州 Release

**验收判据（机器判）**
- 所有层状态 ⊆ {done, empty, partial, failed}
- `failed` 占比 < 15%
- 无 pending

**失败怎么办**：连续失败 3 批就降并发重试；仍不行就停并把原因写进简报。
